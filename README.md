# Flight Route Planner
[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://pythonproject-1-7g4w4sxat2xljtsymxy34o.streamlit.app)

**Live Demo:** [Open App](https://pythonproject-1-7g4w4sxat2xljtsymxy34o.streamlit.app)

An interactive Python application built with Streamlit that finds optimal flight paths and connections between airports using graph search algorithms (BFS and DFS).

## Features
- Search shortest routes by fewest legs (BFS) or explore paths (DFS)
- Visualized route connection data
- Interactive Streamlit web interface
